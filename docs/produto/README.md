# Produto: descoberta e gestão

Objetivo: escolher o primeiro produto com método, usando só ferramentas gratuitas.

## Mapa
| Arquivo | Para quê |
|---|---|
| `00-carta-do-projeto.md` | Por que fazemos isso, critérios de sucesso e de parada |
| `backlog-ideias.md` | Lista de todas as ideias e seus estados |
| `ideias/_TEMPLATE-ideia.md` | Modelo completo para detalhar uma ideia |
| `ideias/ideia-01..03-*.md` | Três ideias para preencher e comparar |
| `comparativo.md` | Critérios, pesos e regras de decisão |
| `decisoes/_TEMPLATE-decisao.md` | Registro curto de decisões |
| `gestao-github-projects.md` | Como montar e usar o quadro |

## Fluxo
Carta → backlog → preencher ideias → `node scripts/compare-ideas.mjs` → validação de uma semana → escolher → MVP em ciclos de 2 semanas.
